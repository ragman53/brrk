Record 01

Reading is easier when the page fits your mind.

When you read to write something of your own, the app should not get in the way. Lines should breathe, pages should reflow, and the important places should be easy to mark.

Brrk turns paper pages and PDFs into a flexible reading space with local notes, tags, and vocabulary lookup. OCR and Markdown are the tools underneath; the goal is better reading, clearer thinking, and easier return to the passages that sparked an idea.

Record 02

Built for active reading

Flexible reading layout

Read captured pages and PDFs in a mobile-friendly layout with adjustable typography, spacing, and Natural or Academic reading modes.

Paper and PDF into one reader

Capture paper pages or import PDFs, then review them in the same focused reader instead of fighting with fixed pages on a phone.

Fusen-style notes

Select a passage, attach a note and tags, and keep small markers beside the reading flow so you can return to your own thoughts later.

Manual cleanup when needed

OCR output can be edited by hand, so a valuable page can become readable instead of staying trapped in a noisy scan.

Catch words while reading

Look up selected English words or short Japanese terms with sentence context, then keep vocabulary encounters connected to the page where you found them.

Local-first, open-source, BYOK

No Brrk account or developer-owned AI backend. Your reading records stay local, the source is public, and AI features use your own API key.

Record 04

Local-first, with explicit AI requests.

Brrk does not operate a developer-owned OCR or AI backend. It has no Brrk account system, no ads, no analytics, and no telemetry.

  • OCR and vocabulary lookup use the user’s own Mistral API key.
  • When OCR is used, selected images or PDFs are sent to Mistral API.
  • When vocabulary lookup is used, the selected word or term and its sentence context may be sent to Mistral API.
  • The Mistral API key is stored locally using Android secure storage.
  • Brrk does not send your documents or API key to the Brrk developer.

Record 05

Open source matters for a reading app.

Reading apps handle personal material. Brrk’s source code is inspectable so users can review the data-flow model, check how Mistral requests are made, and file issues or suggestions in public.
