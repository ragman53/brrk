Record 01

Reading material should be easier to work with.

Paper books are still excellent to read, but awkward to quote, search, and annotate. PDFs are portable, but often uncomfortable on a phone and hard to extract from cleanly.

Brrk helps you convert selected reading material into Markdown, local notes, tags, and vocabulary entries. It is designed for students, researchers, language learners, open-source users, and people curious about practical OCR workflows.

Record 02

What Brrk does

Paper book OCR

Capture a physical page, crop it, and turn the selected image into Markdown with Mistral OCR.

PDF OCR

Import a local PDF and create readable Markdown pages for mobile reading and review.

Markdown reading

Read OCR output as reflowable Markdown with manual edits when OCR needs correction.

Local notes and tags

Select text, save notes, attach tags, and keep reading records in app-private storage.

Vocabulary lookup

Look up selected English words or short Japanese terms with sentence context through Mistral Chat.

Open-source / BYOK design

No Brrk account or developer-owned AI backend. The source is public and AI features use your own API key.

Record 04

Local-first, with explicit AI requests.

Brrk does not operate a developer-owned OCR or AI backend. It has no Brrk account system, no ads, no analytics, and no telemetry.

  • OCR and vocabulary lookup use the user’s own Mistral API key.
  • When OCR is used, selected images or PDFs are sent to Mistral API.
  • When vocabulary lookup is used, the selected word or term and its sentence context may be sent to Mistral API.
  • The Mistral API key is stored locally using Android secure storage.
  • Brrk does not send your documents or API key to the Brrk developer.

Record 05

Open source matters for a reading app.

Reading apps handle personal material. Brrk’s source code is inspectable so users can review the data-flow model, check how Mistral requests are made, and file issues or suggestions in public.
