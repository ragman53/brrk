読みやすく整えて、大事な言葉を拾う。

Brrk は、読んで、考えて、自分の言葉を書く人のためのオープンソース Android 読書支援アプリです。紙の本や PDF をスマートフォン上の小さな読書机に変え、気になる箇所に付箋のようにメモを残し、出会った言葉をその場で拾えます。

Google Group に参加する GitHub でソースを見る
  • オープンソース
  • 広告なし / アナリティクスなし / テレメトリーなし
  • Mistral API キーは自分で用意
  • Android クローズドテスト

グループに参加
Record 01

ページが自分の読み方に合うと、考えやすくなる。

読書から自分の文章を書こうとするとき、アプリは邪魔にならないほうがいい。行間はゆったり、ページは読みやすく流れ、大事な箇所にはすぐ印を付けられるべきです。

Brrk は、紙のページや PDF を柔軟な読書空間に変え、ローカルメモ、タグ、語彙検索で読み返しを助けます。OCR や Markdown はそのための道具です。目的は、読みやすさ、考えやすさ、そしてあとから自分の考えに戻りやすくすることです。

Record 02

能動的に読むための機能

柔軟な読書レイアウト

撮影したページや PDF を、文字サイズ、余白、行間、Natural / Academic モードで読みやすく調整できます。

紙の本と PDF を同じ読書画面へ

紙のページを撮影しても、PDF を読み込んでも、スマートフォンで扱いやすい同じ読書画面で確認できます。

付箋のようなメモ

気になる箇所を選択し、メモとタグを付けて保存できます。読書の流れの中に小さな印を残し、あとから自分の考えに戻れます。

必要なところだけ手で整える

OCR 結果は手動で修正できます。大事なページを、読みづらいスキャンのままにせず、自分が読める形に整えられます。

読んでいる途中で言葉を拾う

選択した英単語や短い日本語語句を、文脈となる一文とともに調べられます。出会った語彙を、そのページの読書体験とつなげて残せます。

ローカルファースト / オープンソース / BYOK

Brrk アカウントや開発者所有の AI バックエンドはありません。読書記録はローカルに保存され、ソースは公開され、AI 機能はユーザー自身の API キーを使います。

Record 03

Brrk の Google Play 公開を手伝ってください。

Google Play で本番公開するには、事前にクローズドテストが必要です。Google Groups から Brrk のクローズドテストに参加し、14日間オプトインを維持してくれる Android テスターを募集しています。

Google Group に参加してアプリをインストールし、UI を確認して、14日間テストに残っていただくだけでも助かります。フィードバックは歓迎ですが、必須ではありません。

Google Group に参加する テスターグループ情報の扱い

テスターアクセスは Google Groups（brrk-closed-test@googlegroups.com）で管理します。Google フォームへの回答は不要です。

テスター要件

  • Android スマートフォン
  • テスター用 Google Group に参加できる Google アカウント
  • 14日間オプトインを維持できること
  • Mistral API キーはテスター参加には任意
  • OCR と語彙検索機能にはユーザー自身の Mistral API キーが必要
  • フィードバックは歓迎ですが必須ではありません
Record 04

ローカルファースト。ただし AI 機能は明示的な送信を伴います。

Brrk は開発者所有の OCR / AI バックエンドを運用していません。Brrk アカウント、広告、アナリティクス、テレメトリーはありません。

  • OCR と語彙検索は、ユーザー自身の Mistral API キーを使います。
  • OCR を実行すると、選択した画像または PDF が Mistral API に送信されます。
  • 語彙検索を実行すると、選択した単語または語句と、その文脈となる一文が Mistral API に送信されることがあります。
  • Mistral API キーは Android のセキュアストレージを使ってローカルに保存されます。
  • Brrk は文書や API キーを Brrk 開発者に送信しません。

Record 05

読書アプリだからこそ、オープンソース。

読書アプリは個人的な資料を扱います。Brrk のソースコードは公開されているため、データの流れ、Mistral へのリクエスト方法、実装内容を確認し、Issue や提案を送ることができます。
