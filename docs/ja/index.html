本と PDF を読みやすい Markdown に。

Brrk は、紙の本と PDF のためのオープンソース Android 読書支援アプリです。ページを撮影し、PDF を読み込み、ユーザー自身の Mistral API キーで OCR を実行し、結果を Markdown、メモ、語彙として保存できます。

クローズドテストに参加する GitHub でソースを見る
  • オープンソース
  • 広告なし / アナリティクスなし / テレメトリーなし
  • Mistral API キーは自分で用意
  • Android クローズドテスト
Tester file 14日

Google Play のクローズドテストに参加し、Brrk をインストールして、テスト期間中オプトインを維持してください。

申し込む
Record 01

読書資料をもっと扱いやすく。

紙の本は読みやすい一方で、引用、検索、注釈づけには手間がかかります。PDF は便利ですが、スマートフォンでは読みづらかったり、きれいにテキストを取り出しにくいことがあります。

Brrk は、選んだ読書資料を Markdown、ローカルメモ、タグ、語彙エントリとして整理するためのアプリです。学生、研究者、語学学習者、オープンソースユーザー、OCR や AI 活用に興味のある人を想定しています。

Record 02

Brrk でできること

紙の本の OCR

物理的なページを撮影し、必要な範囲を切り抜いて、Mistral OCR で Markdown に変換します。

PDF OCR

ローカル PDF を読み込み、スマートフォンで読みやすい Markdown ページを作成します。

Markdown 読書

OCR 結果をリフロー可能な Markdown として読み、必要に応じて手動で修正できます。

ローカルメモとタグ

テキストを選択してメモを保存し、タグを付け、読書記録をアプリ内のローカル領域に保持します。

語彙検索

選択した英単語や短い日本語語句を、文脈となる一文とともに Mistral Chat で調べます。

オープンソース / BYOK

Brrk アカウントや開発者所有の AI バックエンドはありません。ソースは公開され、AI 機能はユーザー自身の API キーを使います。

Record 03

Brrk の Google Play 公開を手伝ってください。

Google Play で本番公開するには、事前にクローズドテストが必要です。Brrk のクローズドテストに参加し、14日間オプトインを維持してくれる Android テスターを募集しています。

参加してアプリをインストールし、UI を確認して、14日間テストに残っていただくだけでも助かります。フィードバックは歓迎ですが、必須ではありません。

クローズドテスターとして申し込む テスター申込情報の扱い

メールアドレスは、Brrk の Google Play クローズドテストへの招待とテスト連絡のためにのみ使用します。

テスター要件

  • Android スマートフォン
  • Play ストアのテスト招待に使う Google アカウントのメールアドレス
  • 14日間オプトインを維持できること

  • OCR と語彙検索機能にはユーザー自身の Mistral API キーが必要
  • フィードバックは歓迎ですが必須ではありません
Record 04

ローカルファースト。ただし AI 機能は明示的な送信を伴います。

Brrk は開発者所有の OCR / AI バックエンドを運用していません。Brrk アカウント、広告、アナリティクス、テレメトリーはありません。

  • OCR と語彙検索は、ユーザー自身の Mistral API キーを使います。
  • OCR を実行すると、選択した画像または PDF が Mistral API に送信されます。
  • 語彙検索を実行すると、選択した単語または語句と、その文脈となる一文が Mistral API に送信されることがあります。
  • Mistral API キーは Android のセキュアストレージを使ってローカルに保存されます。
  • Brrk は文書や API キーを Brrk 開発者に送信しません。
