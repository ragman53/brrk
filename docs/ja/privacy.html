2. Brrk がデバイス上に保存するデータ

Brrk は以下のデータを Android のアプリ専用ストレージにローカル保存します。

  • 紙の本のレコード、ページラベル、撮影したページ画像ファイルへの参照。
  • 読み込んだ PDF のレコードとローカル PDF ファイルへの参照。
  • 紙のページまたは PDF から生成した OCR Markdown。
  • ユーザーが保存した手動 Markdown 編集。
  • メモ、タグ、PDF メモ、語彙定義、語彙の出現例。
  • 同じ画像や PDF への重複 OCR リクエストを避けるための OCR キャッシュ。
  • 読書表示設定と、一度だけ表示される開示事項への同意記録。

Mistral API キーは Android のセキュアストレージを使ってローカルに保存されます。Brrk はアプリデータを受信または保存するサーバーを運用していません。

3. Brrk がデバイス外へ送信するデータ

Brrk は、ユーザーが開始した機能のためにのみデータをデバイス外へ送信します。

機能 送信されるデータ 送信先 目的
紙の本 OCR 撮影または切り抜いたページ画像と、認証ヘッダー内の Mistral API キー。 Mistral OCR API 選択した画像を Markdown テキストに変換するため。
PDF OCR 選択した PDF ファイルと、認証ヘッダー内の Mistral API キー。 Mistral OCR API 選択した PDF を Markdown テキストに変換するため。
語彙検索 選択した単語または短い語句、その語句を含む一文、ソースメタデータ、認証ヘッダー内の Mistral API キー。 Mistral Chat Completions API 短い定義と正規化された語彙エントリを生成するため。

語彙検索では、Brrk は選択した単語または語句と、それを含む一文のみを送信します。語彙検索のためにページ全体や文書全体を送信することはありません。

4. クローズドテスター申込

外部フォームを使って Brrk のクローズドテストに申し込む場合、開発者は Google Play クローズドテストへの招待とテスト連絡の目的で、メールアドレスおよび任意の連絡情報を収集することがあります。このテスター申込情報は Brrk アプリ自体によって収集されるものではありません。申込フォームには API キー、私的な文書、機微な個人情報を入力しないでください。

5. 第三者サービスと共有

Brrk は、ユーザーがこれらの機能を開始したときに、OCR と語彙検索のために Mistral AI を第三者サービスプロバイダーとして使用します。Mistral の API に送信されたデータの取り扱いは、Mistral の規約およびプライバシー慣行に従います。

Brrk は個人データまたは機微なユーザーデータを販売しません。広告、アナリティクス、トラッキング、マーケティングのためにユーザーデータを共有することもありません。

6. 権限

  • カメラ: ユーザーが撮影を開始したときに、物理的な本のページを撮影するためにのみ使用します。
  • インターネット: Mistral OCR と語彙検索リクエストのために使用します。

PDF の読み込みには Android のシステムファイルピッカーを使用します。Brrk は PDF 読み込みのために広範なストレージアクセス権限を要求しません。

7. セキュリティ

  • Mistral へのネットワークリクエストには HTTPS を使用します。
  • Mistral API キーは Android のセキュアストレージを通じて保存されます。
  • アプリデータはアプリ専用ストレージに保存されます。
  • Brrk では Android のフルデータバックアップを無効にしています。

ユーザーのリクエストにより第三者サービスへデータが送信される場合を含め、どのアプリも絶対的な安全性を保証することはできません。デバイス、OS、API 認証情報を安全に管理してください。

8. 保持と削除

ローカルアプリデータは、ユーザーがアプリ内で削除する、Android のアプリデータを消去する、または Brrk をアンインストールするまでデバイス上に残ります。

  • アプリ内で読み込んだ PDF と紙の本を削除できます。
  • メモ、語彙エントリ、語彙の出現例をアプリ内で削除できます。
  • 設定から OCR キャッシュデータを削除できます。
  • Brrk をアンインストールすると、アプリ専用ストレージ内のローカルデータはデバイスから削除されます。

Brrk にはアカウントシステムがないため、削除すべき Brrk アカウントはありません。Mistral に送信されたデータについては、Mistral のポリシーとアカウント管理を確認してください。

9. 子ども

Brrk は子どもを対象としていません。必要な権利と同意がない限り、子どもの個人データを処理するために Brrk を使用しないでください。
